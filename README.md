# 🚗 Dream Car Landing Page - Bootstrap 5

A modern, responsive, and elegant Luxury & Sports Car Landing Page built using **Bootstrap 5**, **Vanilla JavaScript**, and custom **CSS3**.

---

## 📌 About The Project

This website is an interactive landing page designed for a showroom and concierge service specializing in sports cars and luxury vehicles. Crafted with a sleek, premium aesthetic, it offers a clean and fully responsive user experience across all devices.

### ✨ Key Features

- 🎯 **Responsive Navigation Bar**: Fixed-top navbar with custom JavaScript *scroll-spy* functionality that dynamically highlights the current section as you scroll.
- 🖼️ **Dynamic Header Background Slideshow**: Automated background slideshow featuring smooth 5-second fade transitions across curated header media.
- 🛠️ **Services Section**: Highlights 4 key service offerings (*Premium Selection, Certified Technical Inspection, Exclusive Financing, and VIP After-Sales*).
- 🏎️ **Product Showcase**: Curated product cards displaying flagship sports cars (such as the *Porsche 911 Turbo S*, *Mercedes-AMG SL*, and *Lexus LC 500*).
- 📖 **About Us Section**: In-depth story covering company heritage, certified technical inspection standards, and team expertise.
- 💬 **Contact CTA & Footer**: Direct WhatsApp call-to-action button and social media links for seamless engagement.

---

## 🛠️ Tech Stack & Dependencies

- **HTML5** - Semantic markup structure.
- **CSS3 & Custom Styles** (`assets/css/style.css`) - Tailored color system, custom spacing, and transition animations.
- **Bootstrap 5.3.8** - Responsive grid system, utilities, and components (via CDN).
- **Vanilla JavaScript** (`assets/js/script.js`) - Active scroll-spy implementation and background carousel slider logic.
- **FontAwesome** - Vector icons for modern UI elements.

## 🚀 Getting Started

### Prerequisites
A modern web browser (such as Chrome, Edge, Firefox, or Safari). No package manager or complex build setup required!

### Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/malhafiz-dev/landing-page-bootstrap.git
   ```
2. **Navigate into the directory**:
   ```bash
   cd "LandingPage + Bootstrap"
   ```
3. **Open the application**:
   - Double-click `index.html` to open it in your browser.
   - Or use the **Live Server** extension in VS Code for live preview capabilities.
